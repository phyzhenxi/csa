====================
双机机负载的方法
经本人和一个同学之间的测试,很成功.2台电脑当服务器很稳定,估计N人在线都没问题.
====================
例如：
A机为SAAC+数据库+网站   B机为GMSV
A机IP：kuwan.eicp.net   B机IP：yinmo.oicp.net
====================
方法1:
A机：
只需要整个saac目录和数据库文件csadb.mdb,如果有网站系统也放在A机上。
然后设置好ODBC数据源.
使用UE打开SAAC里的acserv.cf 找到
# LSADDRESS
LSADDRESS localhost
把localhost  改成B机的IP：yinmo.oicp.net
====================
B机：
只需要整个gmsv目录,不需要数据库文件和设置ODBC数据源.
使用UE打开GMSV里的setup.cf 找到
# Account Server Name
acserv=localhost
把localhos改成A机的IP：kuwan.eicp.net
====================
启动方法：首先要A机直接启动saac.exe。然后B机直接启动gmsv.exe就OK了，顺序绝对不能乱。关闭服务器的时候先关闭gmsv.exe在关闭saac.exe。
登录器的IP设置采用GMSV端也就是B机器的IP地址：yinmo.oicp.net，别人通过http://kuwan.eicp.net访问网站注册帐号。[PS：网站只能放在A机器上，否则无法通过网站注册账号]
A和B须开放端口：9065 9200 2222，否则无法登陆游戏。
安全方面：请设置好连接账号和密码，不建议采用默认设置的test。
