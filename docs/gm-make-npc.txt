gmsv\data\npc\my\vipshop目录下面的文件自己去看看，是游戏里渔村的2个会员商店.自己改吧:
vipshop.create这个文件里面指定了NPC的一些重要信息,比如创建在哪个地图哪个坐标等等.
-----------------
floorid=2000  这行表示地图的编号,可以对照相关文件或GM工具查询地图编号进行修改.
borncenter=70,69 这个是坐标,不会的开外挂进游戏,外挂上有坐标显示.
name=会员宠物商店 这个很明显是NPC在游戏里先生的名字了.
dir=6 这个是NPC的面朝哪方,自己试验.
其他参数不说了,自己去看资料.
=================================================
下面说说我们要改的文件:
vipitemshop.arg 卖物品文件,请用UE打开修改
vippetshop.arg 卖宠物文件,请用UE打开修改

先说宠物商店vipitemshop.arg文件,看这段:
------------
#玛蕾菲亚
{
MenuStr:玛蕾菲亚二代   需会员点数20
VipPet:MM2,200
}
------------
第1行 #玛蕾菲亚 开头带#的行全部表示注释,这行无效,只用作说明,说白了就是给你自己看的.免得不知道是什么.
第2行 { 必需的.
第3行 MenuStr:玛蕾菲亚二代   需会员点数20 这行表示宠物在商店里显示的信息.前面是宠物名字,后面是价格说明.请根据下一行设置.
第4行 VipPet:MM2,200 关键就是这行了,MM2表示要卖的宠物的编号,可以用GM工具查询或者对照宠物文件取得,后面的200表示需要多少会员点数才能买,就是价格,只是不是游戏币,是会员点.
第5行 } 跟上面的{组合,必须的.
现在明白了没?要想加个宠物在商店里,只要加上面的5行就OK了.1只宠物5行,可以加很多,具体多少还没试过.

下面说说物品商店vippetshop.arg文件,看这段:
-----------------
#运气戒指(精灵王)
{
MenuStr:变身戒指(精灵王)需会员点数20
VipItem:20806,20
}
-----------------
我想不用说什么了,跟上面的宠物商店完全一个的格式.只是中间的2行几个命令不一样.格式完全一样.
